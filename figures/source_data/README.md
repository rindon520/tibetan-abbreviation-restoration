# 图件聚合源数据

本目录包含 8 份 CSV 与 2 份 JSON，只保存冻结实验的汇总数值、调参记录、计数和文件哈希，不保存原始藏文文本、逐条预测、模型权重、样本索引或组身份清单。

| 文件 | 内容 |
| --- | --- |
| `main_comparison.csv` | 主方法与基线的测试 CER、藏文单元错误率及整段匹配率 |
| `context_components.csv` | 同一已训练上下文模型的逐步后处理指标 |
| `context_tuning.csv`, `edit_tuning.csv` | 开发集候选参数搜索结果 |
| `selection_contingency.csv`, `selection_outcomes.csv` | 候选优劣和选择改善、损害、持平的聚合计数 |
| `neural_role.csv` | 纯神经、纯规则和完整去神经控制；后验身份保留 |
| `seed_replications.csv` | 固定划分下 42、43、44 神经种子的全部运行点 |
| `split_summary.json` | 只含分组数量、划分职责及语料哈希的划分摘要 |
| `summary.json` | 绘图参数、实验限制与输入证据文件相对路径/SHA256 |

`summary.json` 中的证据路径指向生成时的本地冻结实验记录；GitHub 不包含这些真实逐条文件。路径与哈希用于核对来源，不表示文件已公开。数值不经重新取样或人工改写。

固定分组为 train/dev/calibration/test = 6,730/962/962/961。神经辅助主结果固定为 seed42，补充种子全部报告；后验去神经诊断不替换主方法，也不证明神经分支必要。TibNorm 使用外部词典和更广泛的正常化规则，资源条件不同。

数据书目按作者提供记录：《藏文缩略语词典》（谢拉编著，民族出版社），以及补充参考的《缩略语词典》（项布旺杰，四川民族出版社）。出版年份、版次、逐条来源对应、录入复核与共享授权仍待补充；本目录不据此公开原文。

绘图命令、正文图号映射和字体依赖见上一层 README。重新计算聚合表应写入独立的 generated 目录，保留这份冻结源表。

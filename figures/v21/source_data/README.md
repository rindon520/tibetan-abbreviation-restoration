# 可公开的 V21 聚合输入

`v21_aggregate.json` 是图2—6的默认数值输入，包含固定划分的规模、方法聚合指标、候选选择结局、联结组自助区间和校准集阈值操作点。JSON 的 `evidence` 保留对应冻结文件的逻辑路径与 SHA256，便于在有权访问实验目录时核对。

本目录不含逐条藏文源文本、还原文本、样本索引、模型权重或私有机器路径。CSV 是作者本地 V21 绘图入口由相同冻结结果生成的聚合源表，包含编辑操作和明确标为定性示意的机制矩阵。

词典书目按作者提供记录：《藏文缩略语词典》（谢拉编著，民族出版社），以及补充参考的《缩略语词典》（项布旺杰，四川民族出版社）；不写 ISBN。出版年份、版次、词条来源对应和录入复核流程仍待补充，公开聚合指标不代替原始文本的共享授权。

方法指标保留数值型 `micro_character_accuracy=1−micro_cer` 和 `exact_match` 字段，分别对应CA和整段EM；没有拷贝字符替换示例或逐条预测。`fig4_comparison.csv` 增加CA比例列，其余冻结值保持不变。

2026-10-27增加`qualitative_fig6`：三种说明性缩写机制×四项结构关联。它不包含真实藏文词例，不是测试类型标注或频数；对应CSV有12个定性关系单元。所有既有实验指标和编辑操作计数保持不变。

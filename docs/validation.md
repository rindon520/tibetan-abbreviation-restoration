# 本地验证

验证环境：Windows，独立 CPython 3.13.9 venv，NumPy 2.3.5、SciPy 1.16.3、scikit-learn 1.7.2、joblib 1.5.2、threadpoolctl 3.6.0。神经训练验证使用现有 PyTorch 2.11.0+cu128；CUDA 可用，设备为 NVIDIA GeForce RTX 5080。

该本地环境安装 pip 数值计算依赖，避免旧 Conda 的 MKL/OpenMP 冲突；通过受限的模块查找器复用本机已安装的 PyTorch 及其必要依赖，没有忽略重复 OpenMP 错误。此环境不进入上传包；普通用户按 README 在干净 venv 中安装即可。

已完成：

- 31 项 unittest：包括原有 26 项测试，完整模型状态、候选错序/截断拒绝、分组互斥与数据哈希校验、选择器 JSON 参数与 scikit-learn 数值预测等价、无参考标签推理。
- `scripts/smoke_test.py`：40 条合成配对的统计训练、完整模型导出、重新加载、批量推理；重新加载的两条保留样例与训练阶段导出的预测一致。
- 1 轮 CPU 编辑标注器训练：16 维、1 层、2 头、batch 8，合成数据；训练、checkpoint 加载及验证/测试预测文件均正常生成。该验证仅确认程序可运行，不构成性能证据。
- 发布审计：`data/` 仅收录指定的三份数据文件及说明；模型权重、论文、日志、外部分词器、二进制与大文件仍排除。

- 完整双路 `infer_pipeline.py` 在已冻结模型上对新源文本完成 CPU 推理，无参考答案输入。

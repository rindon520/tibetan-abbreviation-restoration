# 数据格式与划分

仓库已在 `data/` 收录藏文缩写—还原对照语料和藏文字符集，文件说明、记录数及哈希见 [data/README.md](../data/README.md)。配对语料按原始行号对应：

据作者提供的信息，现有数据整理自谢拉编著的《藏文缩略语词典》（民族出版社），并参考项布旺杰的《缩略语词典》（四川民族出版社）。这里区分作者说明的数据整理来源与补充参考来源，不据此推断两个独立数据集。

| 作者提供的来源 | 已知信息 | 尚待补充 |
| --- | --- | --- |
| 《藏文缩略语词典》 | 谢拉编著；民族出版社；作为数据整理来源 | 出版年份、版次、词条页码与采集复核流程 |
| 《缩略语词典》 | 项布旺杰；四川民族出版社；作者补充的参考来源 | 出版年份、版次、具体参考或采集的词条范围、与配对样本的对应关系 |

以上书名、作者和出版社按作者提供记录；不猜测出版年份或版次。当前代码评估的是这些词典来源配对文本的还原，不是独立古籍正文或 OCR 数据集。原始配对文本现已纳入本仓库；该收录不自动授予公开再分发许可。

- `data/Source.txt`：原始缩写文本，UTF-8（含 BOM），每行一条原始记录。
- `data/Restore.txt`：对应还原文本，UTF-8（含 BOM），同一行号对应同一条记录。
- 两文件各含 10,820 条非空原始记录，必须按相同行号配对；源文件的原始行号必须保留。读取含 BOM 的文本时可使用 `encoding="utf-8-sig"`，不要将 BOM 作为首条文本的一部分。
- `data/tibetan_VCC_7387.txt`：藏文字符集清单，UTF-8（无 BOM），共 7,387 条非空条目，其中有重复项和由多个 Unicode 码点组成的组合形式；不等同于 7,387 个互不相同的 Unicode 字符。没有该文件时，字符基线可以从数据构建词表；正式评估只用训练集构建词表。

句段抽取遵循既有数据约定：源文本由至少两个连续空白分隔，参考文本按 U+0F0D（藏文句末符）分割；只接受源/参考句段数量一致的原始行。这只是自动质量过滤，不等于人工确认每个配对准确。

正式入口为每个句段保存 `source`、`reference`、`parent_line_id`、`segment_in_parent` 和 `group_id`。同一原始行的句段不能跨集合；相同源文本（仅分组时使用 NFC 规范化）关联的原始行也不能跨集合。训练及计分保留原始 Unicode 码点，不静默改变标点或空白。

`records.jsonl`、`split_manifest.json` 与真实模型预测均包含研究数据，只存于本地实验目录，不纳入 Git。论文与代码公开版本应提供数据来源、权限及可获取条件；如无法共享原文，可共享不暴露文本的聚合统计与文件哈希。

候选预测 JSONL 的最小结构：

```json
{"source":"demo1","prediction":"demoONE"}
```

评估文件还需要 `reference`。编辑候选可带 `decisions`（每个位置的 `confidence`、`origin`）、`raw_prediction`，上下文候选可带 `base_prediction`。选择器训练严格检查行数、源文本、参考文本及固定划分中的顺序；不能仅按相同长度猜测对齐。

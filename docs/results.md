# 修正分组协议的聚合结果

当前稿件：《上下文感知转写与候选重排序的藏文缩略词还原方法》，延续原 V21 六图叙事。标题与图件组织调整不改变以下冻结结果；当前正文图号见 [V21 图件说明](../figures/v21/README.md)。

固定分组 seed 42、神经训练 seed 42。train/dev/calibration/test 分别为 6,730/962/962/961 个句段。最终 test 的 961 个句段属于 874 个连通组，无跨集合原始行或 NFC 源文本重叠。评分保留全部原始码点，包括标点。

字符编辑准确率定义为 CA=1−micro_CER；整段还原准确率 EM 为还原结果与参考逐码点完全一致的片段比例。表中均乘100展示，百分数满足 CA/%=100−CER/%。CA和EM使用不同的归一化对象，应分别报告。

| 方法 | 字符编辑准确率 CA (%) ↑ | 整段还原准确率 EM (%) ↑ | micro CER (%) ↓ | Tibetan unit error rate (%) ↓ |
| --- | ---: | ---: | ---: | ---: |
| 复制输入 | 66.6719 | 2.0812 | 33.3281 | 61.1716 |
| TibNorm 默认完整归一化（外部词表） | 71.9236 | 3.4339 | 28.0764 | 52.8257 |
| 全局字符转写 | 71.6662 | 4.3704 | 28.3338 | 55.3851 |
| 全局转写 + 句末符 + 音节词表 | 75.4604 | 6.2435 | 24.5396 | 39.6153 |
| 字符 Transformer Seq2Seq（从头训练） | 40.3541 | 4.2664 | 59.6459 | 55.9018 |
| 上下文转写 + 校正（主候选） | 82.1736 | 13.5276 | 17.8264 | 31.4919 |
| Transformer 编辑标注 + 校正（辅助候选） | 79.5279 | 9.6774 | 20.4721 | 34.9018 |
| 候选重排序 | 82.7122 | 14.2560 | 17.2878 | 30.0612 |

主方法字符编辑准确率CA为82.7122%，整段还原准确率EM为14.2560%（137/961），对应CER为17.2878%。

双路选择将总字符编辑距离从 4,501 降至 4,365，参考字符总数为 25,249，micro CER 降低 0.5386 个百分点，相对降低 3.0216%。按连通组进行 5,000 次成对 Bootstrap，绝对 CER 降幅的 95% 区间为 0.3129–0.7663 个百分点。该区间只反映固定划分和这次训练下的样本重采样变异，不覆盖训练随机性或跨来源泛化。

选择器在 961 条测试句段中选择辅助候选 136 次：84 次编辑距离改善、30 次恶化、22 次持平。两个候选在 688 条句段上不同，辅助候选总体有 163 条比主候选更优；候选存在互补性，但选错仍然发生。

固定同一划分和上下文主模型，补充神经种子 43、44：双路 CER 分别为 17.3710%、17.3472%；三个种子的 CER 均值为17.3353%、CA均值为82.6647%，二者的样本标准差均为0.04284个百分点。整句完全匹配率均值为 14.4988%，样本标准差为 0.21661 个百分点。三个种子均完整报告，保留 seed42 作为主结果，不依据测试结果选择最佳种子。此结果只反映固定词典划分下的神经初始化与相应选择器变异。

外部 TibNorm 使用公开词典与完整归一化规则，资源范围不同，并可能与本语料重叠。字符 Seq2Seq 是从头训练的基线，其弱结果不支持声称优于所有神经或预训练方法。当前语料据作者说明整理自《藏文缩略语词典》（谢拉编著，民族出版社），并参考《缩略语词典》（项布旺杰，四川民族出版社）；出版年份、版次、词条对应和复核标识仍待补充，结论仅限当前配对文本。

后验去神经诊断将辅助候选替换为固定的编辑对齐统计规则，并在独立 calibration 上拟合选择器：CA 82.7043%、CER 17.2957%、整段还原准确率EM 14.5682%。与 seed42 神经辅助的主方法相比，仅多 2 次字符编辑，但多正确还原 3 个句段。因此现有数据不支持“神经候选不可替代”或“神经结构带来主要提升”的结论。此控制在测试候选已经被检查后实施，属于探索性诊断，未替换主实验，也不作为新的确认性结果。

固定神经辅助候选中约 58.9186% 的源字符位置采用规则回退。单独关闭回退的纯神经候选 CER 为 25.4466%，纯规则候选 CER 为 19.8384%。参考答案驱动的候选 Oracle 只能作为上界诊断，不能部署或用于调参。诊断及完整去神经流程：

```bash
python scripts/diagnose_frozen_candidates.py --run-dir experiments/grouped_seed42
python scripts/ablate_neural_candidate.py --run-dir experiments/grouped_seed42
```

全部主实验及消融的数值、整数计数、Bootstrap 区间和语料哈希见 results_summary.json。历史句段随机划分的结果不作为此表的独立泛化证据。
